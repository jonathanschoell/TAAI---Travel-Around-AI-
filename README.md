# Jovia
Jovia is your intelligent, AI-powered travel agency. Plan, personalize, and discover your perfect journey through natural conversation. From inspiration to itinerary, experience a smarter, seamless way to travel.

## Project

Next.js 16 · TypeScript · Tailwind CSS · Supabase (Postgres, Auth, row level security).
Setup instructions (German): [SETUP.md](SETUP.md). Database schema: `supabase/migrations/`.
